    R2.2 — Clarify the “bounding parameters / wall” box re: modern samplers

    • Type: website
    • Location: workshops/06.reinforcement_learning/qmd/hierarchical_modeling.qmd (callout box, ~L195)
    • Status: ✅
    • Comment: “While this is true for direct implementation of MCMC, modern MCMC samplers actually sample in the unconstrained space… they transform bounded parameters to unbounded space and sample there.     R2.5 — stan_binomial.html: reword Effective Sample Size definition

    • Comment: “‘Effective Sample Size (n_eff): This tells us how many truly independent samples we got…’ This can be confusing because we never get any truly independent samples… better to say: The effective sample size is an estimate of the number of independent samples with the same amount of information as the correlated samples we got from our model.”
