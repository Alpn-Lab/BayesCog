    CHEATSHEET.md — BayesCog

    Quick reference for working on this project with Claude.

    Claude Code CLI

    Command Does
    claude Start an interactive session in this repo
    claude --continue Resume the most recent conversation
    claude -p "..." One-shot prompt (non-interactive)

    In-session commands

    Command Does
    /clear Reset conversation context
    /compact Summarize + compress context to keep going
    /cost Show token/cost usage
    Escape Interrupt Claude mid-action

    Project slash commands (.claude/commands/)

    Command Does
    /resume Reload memory files + TASK.md + last SCRATCHPAD entry; report state
    /update-memory Run the 5-step end-of-session memory update
    /status Print concise active / pending / blocked task list

    Trigger phrases (typed in chat, defined in CLAUDE.md §10)

    Phrase When
    continue Same session — re-anchor on last scratchpad + active tasks
    resume New conversation — full context reload
    update memory End of a substantial session — persist progress

    Quarto (the website)

    Command Does
    quarto preview Live local preview in browser (use while editing .qmd)
    quarto render Build full site into _site/ (git-ignored)
    quarto publish gh-pages Deploy site to GitHub Pages (outward-facing — confirm first)

    Edit .qmd source under workshops/**/qmd/, index.qmd, etc. Never hand-edit _site/. Sidebar/navigation and workshop order are defined in _quarto.yml.

    R / Stan environment

    Command Does
    source("setup.R") Restore the renv environment (run once in RStudio)
    library(rstan) etc. Load packages per script as needed
    docker pull sohamir/bayescog:latest Pull pre-built RStudio environment (alternative to renv)

    Scripts: *_main.R = student version (gaps), *_master.R = completed reference.

    Manuscript

    • paper.md (JOSE) and paper_psyarxiv.md (preprint) — keep in sync; .bib files too.
    • paper.pdf is auto-rebuilt by .github/workflows/draft-pdf.yml on push when paper.md/paper.bib/assets/fig1.png change.

    Workflow pattern

    1. Start: type resume (or /resume).
    2. Work: edit .qmd / .R / .stan; quarto preview to check rendering.
    3. End: type update memory.
